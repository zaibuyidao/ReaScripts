# Native Stream Demo

Run `reawebapi-native-stream.lua` with ReaWebAPI v0.3.8.3 or later. Lua returns after opening the window.

Choose PCM, Spectrum, Meter/Loudness, realtime Waveform, MIDI, or a registered stream name. Meter preserves up to 32 hardware or track source channels. Other analysis views retain the first two hardware channels. Selected track uses its pre-FX source audio. **Selected track · aggregate pre-FX sources** adds recursively routed folder children and receive sources, respecting Mute/Solo. Native PCM summation preserves values above `1.0` and phase cancellation. Start playback to accumulate track/aggregate Meter history. Empty folders, buses and upstream tracks preserve aggregate RMS/LUFS accumulation. Other track views can sample at the edit cursor. MIDI inputs must be enabled in REAPER preferences. `reagba.video` requires the separate ReaGBA extension and a loaded ROM.

Meter displays Sample/True Peak, Channel RMS, separate sample/True Peak clip counts, channel/global peak maxima, RMS-M/I, LUFS-M/S/I, LRA bounds and analyzed duration. True Peak, RMS-I, LUFS-M/S/I and LRA follow Cockos loudness_meter. Clip counts are decoded as exact bigint values and displayed as decimal strings. **Meter history** selects playback-only (default) or continuous accumulation for RMS-I/LUFS-I/LRA. Channel-layout changes require reopening the meter. **Reset meter** clears history. **Meter mono analysis** applies Cockos −3 dB global RMS/LUFS calibration when opening a meter. Playback start, seek and capture discontinuities reset history. Stopping track playback holds the last result. Named third-party meters display their producer-defined values without assuming the built-in layout.

The page receives binary packets over the native transport and renders cached data through `requestAnimationFrame`. Detach affects only this page. Device/display queries and native folder watch are low-frequency controls. See [Native Streams](../../docs/native-streams.md).

ReaWebAPI v0.3.8.2+ skips isolated invalid track PCM blocks and resets analysis after recovery. Persistent invalid PCM closes the source with `NATIVE_ERROR`. For connection failures, inspect `(await reaper.stream.getDiagnostics()).transport` for handshake rejection and expired-ticket counters.
